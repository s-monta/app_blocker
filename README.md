# Focus Gate

Pixel 6aを含むAndroid端末向けの、デジタルデトックス用アプリブロッカーです。

## できること

- 端末にインストール済みのアプリを複数選択
- 「今から」「開始・終了日時」「曜日と時間帯」のルールを設定
- 有効期間中に対象アプリが開かれたらホームへ戻し、ブロック画面を表示
- 確定済みルールは終了までアプリ内から編集・削除不可
- ルールをSQLiteへ保存し、APKの上書き更新後も保持

## インストール

1. GitHubの **Releases** を開き、`Focus-Gate-*.apk` をダウンロードします。
2. Androidで「不明なアプリのインストール」を許可してAPKを開きます。
3. Focus Gateを起動し、上部の案内をタップします。
4. Androidのユーザー補助設定で「Focus Gate ブロック機能」を許可します。

以後の更新も同じ場所から新しいAPKを取得し、そのまま上書きインストールできます。アプリIDと署名鍵を固定し、GitHub Actionsの実行番号をバージョン番号にしているため、アンインストールは不要です。

### 手順4でトグルが押せない／グレーアウトしている場合

Android 13以降は、ストア経由でなくAPKを直接インストールした（サイドロードした）アプリについて、ユーザー補助などの機微な設定を初回はセキュリティ保護のため自動でロックします（「制限付き設定」）。Focus Gateは配布方式上これに該当するため、初回はこの制限を解除する必要があります。

1. 端末の「設定」→「アプリ」→「Focus Gate」を開きます。
2. 右上の「⋮」（その他）メニューから「制限付き設定を許可」を選びます。
3. Focus Gateに戻り、あらためてユーザー補助設定から「Focus Gate ブロック機能」を有効にします。

この操作をしないままだと、アプリ自体は起動していても、遮断機能が有効にならず「うまく動いていない」ように見えます。

## ビルドと配布

PC上ではビルドせず、`main`へのpush時にGitHub Actionsが解析・テスト・release APK作成を行います。APKはActions実行画面のArtifacts（90日間）と、Releasesの `Focus Gate 最新版` へ出力されます。

## Android上の制約

通常のAndroidアプリに、OS設定の変更や強制停止まで禁止する権限はありません。このアプリはAccessibility Serviceを利用して対象アプリを即座に遮断しますが、利用者がAndroid設定からユーザー補助権限を無効化した場合やFocus Gateを強制停止した場合は遮断できません。端末を組織管理のDevice Ownerにする方式を除き、この制約をアプリ側で安全に回避することはできません。

## データとプライバシー

- 保存先: アプリ専用領域の `app_blocker.db`（SQLite）
- 保存内容: ルール名、対象パッケージ名、開始・終了日時、曜日
- 画面内容、入力文字、利用履歴を収集・送信しません

## 署名について

上書き更新を常に可能にするため、個人サイドロード用途のrelease署名鍵をリポジトリに含めています。この鍵を削除・変更すると既存インストールへ上書きできません。公開ストア配布へ移行する場合は、別の安全な鍵管理とPlay App Signingを使用してください。
